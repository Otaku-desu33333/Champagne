# Support

Before opening an issue:

1. Update to the latest Champagne release available from [GitHub Releases](https://github.com/Otaku-desu33333/Champagne/releases).
2. Search [existing Champagne issues](https://github.com/Otaku-desu33333/Champagne/issues).
3. Check the troubleshooting guides for [launchers](LauncherTroubleshooting.md) and [stability problems](StabilityTroubleshooting.md).

Use the repository's [issue forms](https://github.com/Otaku-desu33333/Champagne/issues/new/choose) for reproducible app bugs, game compatibility reports, and feature requests. Include your Champagne version, macOS version, selected Wine runtime, graphics backend, and the steps that reproduce the problem.

For crashes or launch failures, attach a diagnostic export with personal paths and other private data removed. Do not attach Windows installers, game files, license keys, or account credentials.

Game compatibility depends on the game, Wine runtime, and graphics backend. A report that works on one combination may not work on another.
