# Governance

Champagne is maintained through the [Champagne GitHub repository](https://github.com/Otaku-desu33333/Champagne). Issues and pull requests are the public record for support requests, proposed changes, and release decisions.

Champagne is derived from the archived Whisky project. Upstream contributors and sources remain credited in the code and relevant documentation. Champagne is independent and is not affiliated with the original project or getwhisky.app.

There is no formal foundation or release committee. For project questions, use the repository's [issue tracker](https://github.com/Otaku-desu33333/Champagne/issues).
